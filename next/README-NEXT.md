# The Shirt Rail in a Next.js hero

This folder mirrors a Next.js project root. Copy both folders into yours:

- `components/shirt-rail/`: the React wrapper, the rack code and its CSS
- `public/shirt-rail/textures/`: the 50 shirt photos (about 2.8 MB)

Then install the exact Three.js version the rack was built with:

```bash
npm install three@0.186.0
```

## Use it

App Router (`app/page.tsx`):

```tsx
import ShirtRailHero from '@/components/shirt-rail/ShirtRailHero';

export default function Home() {
  return (
    <main>
      <section style={{ height: '100svh' }}>
        <ShirtRailHero />
      </section>
      {/* rest of the page */}
    </main>
  );
}
```

The rack fills its parent and centres itself vertically. Give the parent section whatever height the hero should be. It needs at least 390px.

If the `@/` alias isn't set up, use a relative import such as `../components/shirt-rail/ShirtRailHero`.

**Pages Router:** Next only allows global CSS imports in `pages/_app.tsx`. Remove `import './shirt-rail.css'` from `ShirtRailHero.tsx` and add `import '@/components/shirt-rail/shirt-rail.css'` to `_app.tsx` instead.

## Options

- `assetBase`: the public URL of the folder containing `textures/`. The default is `/shirt-rail/`. Change it if you put the photos elsewhere, or set a `basePath`.
- `className`: added to the wrapper div.

## Editing

- **Shirts:** clubs, seasons, notes and personal photos are in `kits.mjs`. To add a personal photo, place it in `public/shirt-rail/photos/` and set `photo: '/shirt-rail/photos/name.jpg'` on that kit.
- **Styles:** all styles are in `shirt-rail.css`, scoped under `.shirt-rail`, so they won't leak into the rest of the site.

This folder is generated by `node export-next.mjs` in the source repo. Edit the source there (`dist/` and `next/`) and re-export rather than editing both copies.
